Дмитриев А. В. ФИТ-241


Список дел с псевдо учетными записями. Данные хранятся локально, не используйте реальные учетные данные, авторизация учебная.

Регистрация происходит успешно если в почте 1 символ '@' и нет пробелов, логин уникальный и без пробелов, а пароли совпадают и длиннее 6 символов.

Вход происходит успешно если пароль и логин верны.

Выход происходит если пользователь вошел, в противном случае ничего не происходит.

Задачи отображаются если пользователь вошел, иначе перенаправляется на страницу входа.


для запуска: установите nodejs, перейдите в папку с репозиторием, затем npx install, затем npm run build, затем npm run preview

для разработки: установите nodejs, перейдите в папку с репозиторием, затем npx install, затем npm run sass:dev, затем npm run vite:dev (в отдельном окне)
